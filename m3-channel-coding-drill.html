Last-minute list. Read the red flags first, then run each recipe once on scratch paper.

Red flags (easy to mix up)

  • Source coding removes bits (compression). Channel coding adds redundant bits to fight channel noise.
  • Block codes use lowercase (n, k): n = codeword bits, k = message bits. Convolutional codes use capital (N, K, M): N = output bits per step, K = input bits per step, M = number of shift registers. Different meanings, so don't mix them.
  • Code rate R = k/n < 1 (efficiency). Redundancy = n/k > 1 (per the slide formula). One is the reciprocal of the other.
  • Parity check = error detecting only, misses an even number of errors, can't locate the bit. Repetition = error correcting (majority vote) but poor bandwidth and weak against burst errors.
  • Linear code test: the all-zero codeword must be present, AND the XOR of any two codewords must be another codeword. Missing 00…0 ⇒ not linear immediately.
  • dmin = wmin only for linear codes. wmin excludes the all-zero codeword.
  • G = [Ik | P] (k × n). H = [PT | In−k] ((n−k) × n). Both are for c = [m | b] (message bits on the left). If the parity comes first, swap the blocks.
  • s = rHT depends only on the error pattern (s = eHT). s = 0 means no error OR an undetectable error (e is itself a codeword).
  • Cyclic codeword bit order: MSB on the left = highest power of x. c = 1100010 ↔ x⁶ + x⁵ + x.
  • Systematic cyclic: b(x) = xrm(x) mod G(x), then c(x) = b(x) + xrm(x). The parity is the remainder, not the quotient.
  • Trellis convention: upper branch = input 1, lower branch = input 0. Always start AND end at state 00 (append M zeros to flush).
  • Hard decision → Hamming distance. Soft decision → Euclidean distance (keeps the voltages). Viterbi = MLSE with the Hamming metric, keep the smallest path cost at each state.

Formulas to have cold

  • G(dB) = (Eb/N₀)uncoded − (Eb/N₀)coded at the same BER. Slide 8: 14 − 9 = 5 dB at 10⁻⁶.
  • R = k/n. Redundancy = n/k. Received words = 2n, valid codewords = 2k.
  • c = mG. GHT = 0. xHT = 0 for valid x. s = rHT = eHT. c = r ⊕ e.
  • 2n−k syndromes, 2k error patterns each. Syndrome table is 2n−k × 2k.
  • dH(a,b) = wH(a ⊕ b). dmin = wmin (linear).
  • Cyclic shift: ci(x) = xic(x) mod (xn + 1). Non-systematic: c(x) = am(x)G(x). Valid iff c(x) mod G(x) = 0.
  • s(x) = r(x) mod G(x), degree < n − k.
  • Convolutional: cj(l) = Σi=0M gi(j) b(l−i) = g(j) ∗ b(l). R = K/N. States = 2M. Output length = N × (input bits + M).
  • dH = Σ ri ⊕ ci (hard). dE = √Σ(ri − ci)² (soft).

Procedure recipes

  • Code table → G: write each code bit as a combination of message bits (look at its column), then G's column j = the coefficients of cj. Equivalently, G's rows = the codewords for m = 10…0, 01…0, ….
  • G → H: split off P (the columns after Ik), transpose it, append In−k.
  • Validity / syndrome: s = rHT. Each s bit = XOR of the r bits where that row of H has a 1.
  • Syndrome decoding (single error): s ≠ 0 → find the column of H equal to s → flip that bit of r → read m from the first k bits.
  • Systematic cyclic encode: r = n − k → xrm(x) → long-divide by G(x) with XOR → remainder b(x) padded to r bits → c = [m | b].
  • Convolutional encode: table with columns l, b(l), b(l−1), b(l−2), c₁, c₂. Registers start at 0 → shift right every step → append M zeros → interleave c₁c₂.
  • State diagram: for each state (S₁S₂) and input b: next state = (b, S₁), output from the equations. Label each arrow "input/output".
  • Viterbi: for each received pair, branch metric = Hamming distance to the branch output → path cost = previous cost + branch metric → at each state keep the cheaper incoming path (cross out the other) → after the flush, trace back from 00 → read inputs (upper = 1, lower = 0) and outputs.
