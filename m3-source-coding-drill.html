Red flags (easy to mix up)

  • High probability → LOW self-information → SHORT codeword. Rare events carry more information and get longer codewords.
  • Entropy is maximum when symbols are equiprobable (H = log₂K). But a BSC with error probability p = 0.5 is the worst channel (C = 0). Equiprobable inputs are good; an equiprobable error is bad.
  • BSC p → 1 is not a bad channel: C → 1 because it consistently flips the bits, so the receiver just inverts them.
  • Prefix-free ⇒ uniquely decodable, but not the reverse. Kraft ≤ 1 does NOT prove a given code is prefix-free (deck Example 2, Code III: satisfies Kraft but "0" is a prefix of "01").
  • Kraft > 1 ⇒ not uniquely decodable, so it can't be a prefix code.
  • Source coding removes redundancy (compress). Channel coding adds redundancy (protect). Part 1 = source coding only.
  • Shannon's 1st theorem (noiseless / source coding): H ≤ L̄ₙ/n < H + 1/n. Shannon's 2nd theorem (noisy / channel coding): RsH(S) ≤ RcC.
  • Likelihood = P(y|x), the transition probability (data given hypothesis). Posterior = P(x|y). A priori = P(x). Marginal = P(y).
  • Max a priori uses only P(x) and ignores what was received. MAP (a posteriori) uses P(x|y). ML uses P(y|x).
  • Transition matrix: each row = one input x, sums to 1. Columns do NOT have to sum to 1.
  • Joint entropy: H(X,Y) ≤ H(X) + H(Y), with equality only if X and Y are independent (then I = 0). The recording said "≥", which is backwards.
  • Units: base 2 = bits (Shannons), base 10 = Hartleys, base e = nats. On the calculator, type the base 2 explicitly.

Formulas to have cold

  • No. of codewords = radixn. ASCII: 2⁷ = 128.
  • I(si) = logb(1/pi). H(S) = Σ pi logb(1/pi), 0 ≤ H ≤ logbK.
  • Hb(p) = p log₂(1/p) + (1−p) log₂(1/(1−p)). Hb(0.5) = 1, Hb(0.2) = 0.7219, Hb(0.1) = 0.4690.
  • L̄ = Σ pili. η = H(S)/L̄ (Lmin = H). Kraft: Σ 2−li ≤ 1 (general: Σ r−li ≤ 1).
  • li = ⌈log₂(1/pi)⌉ ⇒ H ≤ L̄ ≤ H + 1. Extension: H(S̄) = nH(S), H ≤ L̄ₙ/n ≤ H + 1/n.
  • P(xi,yj) = P(yj|xi)P(xi). P(yj) = Σi P(yj|xi)P(xi). In matrix form, p(Y) = p(X)·P.
  • Bayes: P(x|y) = P(y|x)P(x)/P(y).
  • I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X) = H(X) + H(Y) − H(X,Y) ≥ 0.
  • C = max over P(x) of I(X;Y). CBSC = 1 − Hb(p).
  • Info rate = H(S)/Ts = RsH(S). Capacity per second = C/Tc = RcC. Reliable if RsH(S) ≤ RcC.

Code-building recipes

  • Shannon: sort p descending → li = ⌈log₂(1/pi)⌉ → pk = sum of all probabilities above it (first = 0) → convert pk to binary by repeated ×2, keep the integer bit, continue with the fraction → codeword = first li bits after the point.
  • Shannon‑Fano: sort descending → split the list into 2 groups with sums as close as possible → upper group gets 0, lower gets 1 → keep splitting each group until every symbol is alone. Ties = multiple valid answers.
  • Huffman: sort descending → merge the two smallest into one node (label the branches 0/1) → re-sort → repeat until the total is 1.0 → read each codeword by tracing from the root (right) back to the symbol (left). Ties = multiple valid answers, but L̄ is always the same minimum.
  • n‑th extension: list all Kn super-symbols → multiply probabilities (DMS is i.i.d.) → run the algorithm on the new list → H(S̄) = nH(S), η = H(S̄)/L̄ₙ, bits per original symbol = L̄ₙ/n.
  • After any code: compute H, L̄, η, Kraft sum, and check that no codeword is a prefix of another.
